# Day 12: Arrays, Enums and Object-Oriented Programming (Java)

## Overview
Covers Object-Oriented Programming in Java (JDK 25): Encapsulation, Runtime Polymorphism, Enums, Abstract Classes, Interfaces, 2D/Jagged Arrays, and Composition vs Inheritance.

## Modules
1. **Set 1: Insurance Policy Hierarchy** - `MotorPolicy`, `HealthPolicy`, `TravelPolicy`, `HomePolicy` (OCP proof), 2D & jagged arrays.
2. **Set 2: Vehicle Rental System** - `Car`, `Bike`, `Van`, `Insurable` interface, and SRP refactoring of God classes.
3. **Set 3: Hospital Billing Model** - `OutPatientVisit`, `InPatientVisit`, `EmergencyVisit`, method overloading/overriding, and composition models.
