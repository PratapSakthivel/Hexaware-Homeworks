# Day 15: Java 8 Features – Lambda, Functional Interfaces, Optional and Date-Time

## Overview
Comprehensive implementation of modern functional Java features (JDK 25): `Predicate` composition, `Optional` patterns, custom `@FunctionalInterface`, Method References, and the `java.time` API (`ZonedDateTime`, `ChronoUnit`).

## Modules
1. **Set 1: Order Validation Rules** - 5 combined Predicates, Function pipelines, Optional refactoring.
2. **Set 2: Fee and Discount Engine** - Custom `DiscountRule`, `andThen` vs `compose`, 4 method reference types.
3. **Set 3: Invoice Due-Date Calculator** - `ZonedDateTime` conversions, working-day holiday calendar, time-zone boundary tests.
