# Day 13: Interfaces, Static and Final, String API and Object Class (Java)

## Overview
Covers Core Java Object & String APIs (JDK 25): `equals()` and `hashCode()` contracts, value Records, String Constant Pool mechanics, Text Blocks, `StringBuilder` benchmarking, `static`/`final` semantics, and Pattern Matching for `instanceof`.

## Modules
1. **Set 1: Customer Master De-duplication** - `Customer` class with normalized email equals/hashCode, `HashSet` proof, marker vs functional interfaces.
2. **Set 2: Invoice Text Formatter** - `StringBuilder` vs `StringBuffer` 1000-item benchmark, Text Block formatting, `instanceof` pattern matching.
3. **Set 3: Attendance Report Generator** - String parsing, pipe delimiter validation, immutable `AttendanceRecord`, String immutability note.
