# Day 14: Collections Framework and Generics (Java)

## Overview
Comprehensive exploration of the Java Collections Framework (JDK 25): `PriorityQueue`, `LinkedHashSet`, `TreeSet`, `HashMap` vs `TreeMap`, bounded generics (`Repository<T>`), wildcard variance (`? extends Course`), and wrapper Integer cache traps.

## Modules
1. **Set 1: Support Ticket Queue** - Multi-level `Comparator`, `LinkedHashSet` duplicate removal, `Iterator.remove()` thread safety.
2. **Set 2: Retail Inventory Manager** - `HashMap` lookups, natural `Comparable`, `ArrayDeque` activity log, Integer caching trap.
3. **Set 3: Course Waitlist** - Waitlist `PriorityQueue`, wildcard capacity summation, `Collections` utility suite.
